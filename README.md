## Entry

`main.py` (Python 3 standard library only, no network, no randomness)
writes one original one-line dad joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output/entry.txt`):

> I told my car to take a brake. It said, 'I'm already exhausted.'

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
